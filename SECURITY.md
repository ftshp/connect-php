# Security policy

Please do not report security vulnerabilities in public issues, pull requests or discussions.

Report them through GitHub's private vulnerability reporting: open the [Security tab](https://github.com/ftshp/connect-php/security) of this repository and choose "Report a vulnerability". Include the version, a description of the problem and, if you can, steps or code to reproduce it.

You will get an acknowledgement within five working days.

## Supported versions

Security fixes are released for the latest minor version. Before 1.0.0 that is the newest 0.x release, so upgrade to it to get a fix. Each fix is published as a GitHub security advisory and listed in the [changelog](CHANGELOG.md).
